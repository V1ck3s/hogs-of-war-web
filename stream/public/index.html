Controls

Arrows: move · X or Space: Cross (confirm, fire) · C: Circle · S: Square · D: Triangle · E / R: L1 / R1 · F / G: L2 / R2 · Enter: Start · Backspace: Select. Esc: room panel · T: chat · F11: fullscreen. Keys can be remapped, gamepads are detected.
