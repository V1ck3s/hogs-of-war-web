Insérez votre disque

Sélectionnez votre propre copie du jeu PlayStation Cochons de Guerre (version française, SLES-02766) : le fichier .cue avec ses pistes .bin, une image .chd, ou directement l’archive .zip. Le disque reste sur votre ordinateur : rien n’est envoyé au serveur.

Pourquoi la version PlayStation ?

Ce portage exécute le code original du jeu PS1 dans une PlayStation virtuelle compilée en WebAssembly : l’intelligence artificielle, les voix françaises de Cochons de Guerre, la musique et les textes sont ceux de la version PlayStation, à l’identique.

Facultatif : un fichier .sbi (protection LibCrypt) de votre disque peut être ajouté à la sélection.

Multijoueur en ligne

Chaque joueur utilise son propre disque. La partie de l’hôte est partagée au moment où vous rejoignez, puis toutes les consoles avancent en parfaite synchronie.

Salon

    Comment jouer à plusieurs
    1. L’hôte crée un salon et partage le code (ou le lien).
    2. Les amis chargent leur disque puis rejoignent avec le code.
    3. Dans le menu du jeu, choisissez MULTIJOUEUR et réglez autant d’emplacements sur JOUEUR 1…4 que de participants (les autres en CPU ou OFF).
    4. Le jeu se joue au tour par tour sur la manette 1, partagée par tout le salon : celui qui joue garde la main ; après 2 secondes sans action, le prochain joueur qui appuie sur un bouton prend la manette.
    Commandes clavier

    Flèches : déplacement · X : Croix · C : Rond · S : Carré · D : Triangle · E/R : L1/R1 · F/G : L2/R2 · Entrée : Start · Retour arrière : Select. Tab (maintenu, solo) : avance rapide pendant la réflexion de l’IA. F2/F4 : sauver/charger l’état. Les manettes USB/Bluetooth sont reconnues automatiquement.
