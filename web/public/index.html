Insert your disc

Select your own copy of the PlayStation game Cochons de Guerre (French version, SLES-02766): the .cue file with its .bin tracks, a .chd image, or the .zip archive directly. The disc stays on your computer: nothing is sent to the server.

Remembered disc:
Why the PlayStation version?

This port runs the original PS1 game code in a virtual PlayStation compiled to WebAssembly: the artificial intelligence, the French voices of Cochons de Guerre, the music and the text are exactly those of the PlayStation version.

Optional: a .sbi file (LibCrypt protection) for your disc can be added to the selection.

Online multiplayer

Each player uses their own disc. The host's game is shared when you join, then every console runs in perfect sync.

Room

    How to play together
    1. The host creates a room and shares the code (or the link).
    2. Friends load their disc, then join with the code.
    3. In the game menu, choose MULTIJOUEUR and set as many slots to JOUEUR 1…4 as there are participants (the others to CPU or OFF).
    4. The game is played turn by turn on controller 1, shared by the whole room: whoever is playing keeps it; after 2 seconds without input, the next player to press a button takes the controller.
    Keyboard controls

    Arrows: move · X: Cross · C: Circle · S: Square · D: Triangle · E/R: L1/R1 · F/G: L2/R2 · Enter: Start · Backspace: Select. Tab (held, solo): fast-forward while the AI is thinking. F2/F4: save/load state. USB/Bluetooth gamepads are detected automatically.
